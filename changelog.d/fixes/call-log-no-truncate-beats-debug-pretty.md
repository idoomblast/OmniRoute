- **fix(logging): `CALL_LOG_NO_TRUNCATE` now wins over debug pretty-printing in call-log artifacts** — `serializeArtifactForStorage()` checked `CHAT_DEBUG_FILE` / `APP_LOG_LEVEL=debug` before `CALL_LOG_NO_TRUNCATE`, so when both were enabled the debug path won and wrote full payloads **pretty-printed** (`JSON.stringify(artifact, null, 2)`), roughly doubling artifact bytes. No-truncate mode now serializes compact regardless of debug mode; debug-only setups keep their pretty output. Regression-tested in `tests/unit/call-log-no-truncate-minify.test.ts`.
